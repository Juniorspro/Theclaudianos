# Mariano Peak

Juegos web. Un juego = **un HTML autocontenido**, three.js desde CDN, se prueba **en el celular,
en vertical (412×892)**.

| ruta | qué es |
|---|---|
| `juegos-pc/Arrabal.html` | **Pelea con cartas.** 3 contra 3, seis luchadores originales, gestos táctiles, campaña y cofre. |
| `juegos-pc/Chicharra.html` | **El juego de acá.** Matamarcianos vertical: oleadas, jefes, tienda, música y efectos sintetizados. |
| `juegos-pc/Bosque.html` | Juego VHS de terror, de otra línea de trabajo del repo. Referencia, no se toca. |
| `.claude/skills/` | Las tres skills del repo: `graficos`, `assets-ia`, `banco`. |
| `herramientas/rezona/rz.py` | Cliente stdio del MCP de Rezona. |
| `docs/GUIA-JUEGOS.md` | La receta: qué pedirle a Rezona, cómo procesarlo y qué hacer en el motor. |
| `memoria/` | Lo que ya se sabe, en notas cortas. Se lee `memoria/INDICE.md` al arrancar. |

Para jugar: abrí el HTML en el navegador del celular. No hay build ni servidor.

El repo es compartido entre sesiones: lo común son las **skills** y las herramientas, no los juegos.
Cada juego vive en su propio HTML.

Las reglas de trabajo y la bitácora están en [`CLAUDE.md`](CLAUDE.md).
